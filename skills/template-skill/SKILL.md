# Template Skill

This is a template skill demonstrating the basic structure of a Springo skill.

## How to Create a Skill

1. Create a folder in the `skills` directory
2. Add a `SKILL.md` file with YAML frontmatter
3. Write instructions in markdown format

## Frontmatter Fields

- `name`: Unique identifier for the skill (required)
- `description`: When to use this skill (required)

## Example Usage

When a user asks to use this skill, follow these instructions:
1. Greet the user
2. Explain what this template does
3. Guide them to create their own skill
